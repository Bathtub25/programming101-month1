# Challenge 4: Reverse a List

## Problem and interface
Return a new list containing the input items in reverse order.

Implement `reverse_list(items)`. Return the answer so callers can check it; printing examples is optional.

## Rules
Do not use reverse(), reversed(), or reverse slicing. Leave the input unchanged.

## Examples to check
| Arguments | Expected result |
| --- | --- |
| `[1, 2, 3, 4, 5]` | `[5, 4, 3, 2, 1]` |
| `[]` | `[]` |
| `[9]` | `[9]` |

## Before coding
Write three to six steps in English. Trace an example with a small table of changing variables. Add one test of your own and predict its answer.

## Hint
An index can start at the last position and move toward zero.

## Stretch challenge
Reverse a string manually and compare front-insertion with appending.

## Done when
Your function meets the contract, passes the listed cases and your additional case, and you can explain why it works. For functions accepting lists, confirm the input is unchanged unless the stretch explicitly asks for in-place changes.
