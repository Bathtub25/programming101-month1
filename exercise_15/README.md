# Exercise 15: Algorithm Race

## Goal
Search an ascending list of integers using a linear scan and a binary search. Return whether target is present.

## Workflow
1. Read [challenge.md](challenge.md) and describe your steps in plain English.
2. Predict results and trace one example by hand.
3. Implement your attempt in [solution.py](solution.py).
4. Run `python3 exercise_15/solution.py` from the repository root and check the examples and edge cases.
5. Explain what worked and revise your attempt before opening [reference_solution.md](reference_solution.md).

## Coach talk track
“If a number is too large at the middle of a sorted row, which half can be ignored?”

Ask the trainee to explain their next step before suggesting a change. Use the hint only after they have tried tracing a small example.

## Reflection
- What did your algorithm remember at each step?
- Which edge case changed your thinking?
- How does the work change when the input grows?
